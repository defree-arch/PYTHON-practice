# Менеджер паролей

Консольный менеджер паролей на Python.

## Возможности
- вход по паролю (хранится только соль и хеш scrypt)
- пароли сервисов шифруются (Fernet, ключ выводится из пароля для входа)
- хранение в SQLite, запросы с параметрами
- генератор паролей на `secrets`
- ввод паролей без отображения на экране, три попытки входа

## Запуск
```bash
pip install -r requirements.txt
python main.py
```

## Структура
- `main.py` — меню и сценарии
- `storage.py` — работа с базой SQLite
- `crypto_utils.py` — хеширование, ключ, шифрование
